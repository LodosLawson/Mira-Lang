**Mira** is a modern, avant-garde programming language focused on visual excellence, GPU-accelerated graphics, and seamless cross-platform deployment. Whether you are building a high-performance desktop simulation or a lightweight web animation, Mira provides the tools to do it with minimalist and elegant code.

## ✨ Key Features
- 🚀 **Self-Contained IDE:** Install the VSCode extension and start coding immediately. No complex setups.
- 🎨 **Unified Graphics Engine:** Write once, render on Native GPU or Web Canvas.
- ⚡ **High Performance:** Optimized bytecode execution for complex math and animations.
- 📦 **Rich Standard Library:** Built-in support for 2D/3D graphics, advanced math, and collections.

## 🚀 Quick Start
1. **Install VSCode Extension:** Download `mira-lang-1.0.0.vsix` from our [Releases](https://github.com/LodosLawson/Mira-Lang/releases) and install it.
2. **Create a File:** Create `hello.mira`.
3. **Write Code:**
   ```mira
   createCanvas(800, 600);
   setFillStyle("#6200ee");
   fillRect(100, 100, 200, 200);
   renderCanvas2d();
   ```
4. **Run:** Click the **"Run Mira"** button in the top right corner.

## 📂 Project Structure
- `src/`: Java source code for the core compiler and engine.
- `stdlib/`: Standard library functions written in Mira.
- `examples/`: Stunning visual demos (Solar System, Particle Engine, etc.).
- `vscode-mira-extension/`: Source code for the VSCode IDE integration.
