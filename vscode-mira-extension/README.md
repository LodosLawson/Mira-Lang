# Mira Language Support for VS Code

Official language support for the **Mira** programming language.

## Features
* Syntax highlighting for `.mira` files
* Auto-completion brackets and quotes
* Smart commenting support
* Specialized highlighting for Mira Graphics API (`renderCanvas2d`, `clearCanvas`, etc.)

## Usage
Simply install this extension, and any file ending in `.mira` will be automatically detected.

Enjoy writing fast and elegant code in Mira!
