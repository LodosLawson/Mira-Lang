# Mira Programming Language

Welcome to the **Mira** ecosystem! This is a modern, fast, and elegant programming language that supports native GPU-accelerated graphics and dual-mode web rendering.

## Installation

### 1. Set Up the Compiler
To use the Mira compiler from anywhere on your computer:
1. Extract this `.zip` folder to a permanent location (for example: `C:\MiraCompiler`).
2. Add that folder to your System `PATH` environment variable.
3. Open a terminal and run `mira` to launch the IDE!

### 2. VSCode Extension
We provide an official VSCode extension for syntax highlighting and automatic compilation:
1. Open VSCode.
2. Go to Extensions -> Click the `...` menu -> **Install from VSIX...**
3. Select the `mira-lang-1.0.0.vsix` file included in this folder.
4. You can now use the "Run (Play)" button in the top right corner of VSCode to run any `.mira` file!

## Running Code
You can run code via terminal:
```bash
mira test.mira
```
Or just type `mira` to open the IDE.

Enjoy building!
